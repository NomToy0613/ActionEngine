# 自作CGエンジン
**タイトル**

Action Engine

**概要**

C++で構築した自作3Dソフトウェアレンダリングエンジンです。

**実装項目**

・数学ライブラリ（Vector3 / Matrix4x4 / Quaternion / Transform / Camera / Projection）
・パイプライン（Sutherland-Hodgmanクリッピング、バックフェースカリング、Zバッファ付きラスタライザ）
・テクスチャ（BMPローダー、パースペクティブコレクト補間
