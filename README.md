# ActionEngine

![デモ](ここに画像のパス)

C++ で開発している自作3Dゲームエンジンです。
GPU やゲームエンジンをブラックボックスとして使うのではなく、レンダリングパイプラインとエンジンの構成を自分で実装し、理解することを目的にしています。
最終目標は、このエンジンだけで3Dアクションゲームを作れる環境を作ることです。

## 特徴

- GPU API を使わず、C++ と Win32 API だけで3D描画パイプラインを実装
- ベクトル・行列・クォータニオンの数学ライブラリを自作(DirectX と同じ左手座標系・深度 0〜1)
- 背面カリング、Sutherland–Hodgman 法による同次座標でのクリッピング
- エッジ関数によるラスタライズ、深度バッファ、パースペクティブコレクト補間によるテクスチャマッピング
- 描画部分を `Renderer` インターフェースで分離し、同じシーンをソフトウェア版と DirectX 11 版で描画(Tab キーで切り替え)
- OBJ モデル・BMP テクスチャの読み込みを自作

| | ソフトウェア版 | DirectX 11 版 |
| --- | --- | --- |
| 描画 | CPU で1ピクセルずつ | GPU(頂点シェーダ・ピクセルシェーダ) |
| FPS | 約64 | 144(モニタの上限) |

## 1フレームの流れ

```
Application(メインループ)
  メッセージ処理 → 経過時間の計測 → GameUpdate → BeginFrame → GameRender → EndFrame
                                                        ↓
Scene
  View・Projection をセット → GameObject ごとに World 行列をセットして DrawMesh
                                                        ↓
Renderer(共通インターフェース)
  ├ SoftwareRenderer:座標変換 → 背面カリング → クリッピング → ラスタライズ → 深度テスト → 表示
  └ D3D11Renderer  :頂点シェーダ → (GPU の固定機能) → ピクセルシェーダ → 表示
```

ゲーム側(Scene・GameObject)は `Renderer&` しか知らないため、ゲーム側のコードを変えずに DirectX 11 版を追加できました。

## 操作方法

| 操作 | キー |
| --- | --- |
| ペンギンの移動 | W / A / S / D |
| カメラの向き | マウス左ドラッグ |
| ソフトウェア版 / DirectX 11 版の切り替え | Tab |

## ビルド方法

WSL 上で MinGW-w64 を使い、Windows 用の実行ファイルをクロスコンパイルします。

```bash
make
```

`ActionEngine.exe` ができるので、Windows 側でリポジトリのフォルダから実行します(`Assets/` と `Shaders/` を相対パスで読み込みます)。

## 技術的な挑戦

- **Near 面クリッピングでのフリーズ**:カメラの後ろにある頂点(w ≤ 0)が残ったまま他の面のクリッピングをすると、判定が壊れてフリーズした。Near 面を最初に処理するように直して解決した。
- **FPS が30で頭打ち**:`Sleep(16)` が Windows のタイマーの刻み(約15.6ms)のせいで実際には約31ms 眠っていたことを、計測で突き止めた。`QueryPerformanceCounter` に変えて `Sleep` を削除した。
- **ピクセルシェーダでの法線**:ピクセルシェーダは三角形の頂点を知らないため、`ddx`/`ddy` で隣のピクセルとのワールド座標の差から面の法線を求め、ソフトウェア版と同じフラットシェーディングを再現した。
