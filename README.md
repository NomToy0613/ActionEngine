# Action Engine

### 概要

C++ / Win32で構築中の自作3Dグラフィックスエンジンです。
現在はGPU APIを使わず、座標変換からラスタライズまで全てCPU上でソフトウェア実装しています。
これは3Dグラフィックスパイプラインの内部構造を自分の手で理解するための意図的なステップであり、
将来的にはDirectXとの統合によりGPUレンダリングへの移行を予定しています。

### 実装済み機能

- **数学ライブラリ**：Vector3 / Matrix4x4 / Quaternion / Transform / Camera / Projection
- **レンダリングパイプライン**：Sutherland-Hodgmanクリッピング、バックフェースカリング、Zバッファ付きラスタライザ
- **テクスチャ**：BMPローダー（24/32bit対応）、パースペクティブコレクト補間

### 技術的な挑戦

開発中に直面した問題とその解決策の一部です。

- **Near面クリッピングの順序問題**：クリッピング処理で他の平面より先にNear面を処理する必要があった。w<0の頂点が残ったまま他平面の内外判定を行うと、バウンディングボックスの計算が破綻しラスタライズループが暴走・フリーズする不具合が発生したため。
- **パースペクティブコレクト補間**：スクリーン空間で単純にUVを線形補間すると遠近感による歪みが出るため、u/w, v/w, 1/wを補間してから逆算する方式で実装。
- **Winding orderとカリングの整合性**：頂点の並び順とバックフェースカリングの表裏判定が密接に連動しており、インデックス順のミスで面が消える不具合を経験。

### 開発プロセス

本プロジェクトはユーザーストーリーを起点に要件を整理し、スプリント単位で段階的に機能を実装しています。
各スプリントの完了条件・マイルストーンは事前にドキュメント化した上で開発を進めており、
「動くものを積み上げる」のではなく「計画→実装→検証」のサイクルを意識した進め方を採っています。
全体のユーザーストーリーとマイルストーン定義は [こちら](./docs/ActionEngineユーザーストーリー.pdf) にまとめています。

### 開発方針について

本プロジェクトは学習を主目的としており、3Dグラフィックスパイプラインの各処理（座標変換・クリッピング・
ラスタライズなど）は自身で仕組みを理解した上で実装することを重視しています。
一部、実装の詰まった箇所や設計判断の相談にAIツールを活用していますが、
コードを写経するのではなく、原因の切り分けや動作原理の理解を経てから反映する形で進めています。
